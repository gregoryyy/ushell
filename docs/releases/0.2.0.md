# ush 0.2.0

The first release of `ush`, the `//` shell for zsh: ask in plain language, and ush proposes the
shell command that answers it, on your command line. 0.2.0 is the code of 0.2.0-rc1 (the same
commit, b4f9d82), built and checked again as 0.2.0; no reports against the candidate needed a fix.

## What it does

- **Propose mode (default):** `// why is my disk full?` puts a command on your command line. Enter
  runs it in your shell, Down explains it (what each part does, which files and network it reads
  and writes), Esc removes it. `//` continues with what you ran, its exit status and output.
- **Agent mode (`ush --run //…`):** ush investigates on its own. It runs commands it can verify as
  read-only, and asks before anything else.
- **Models:** Anthropic (an API key, kept in the macOS keychain or a 0600 file), or a local model in
  Ollama, where nothing leaves the machine. An optional second model, the checker, judges each
  command against your requests.
- **Also:** `ush explain COMMAND`, an allowlist for harmless commands (`ush allow add kubectl get`),
  history and replay without AI, and `sudo ush` with a root-owned install.

## Install

**Homebrew** (macOS and Linux; builds from the tagged source with Go):

```sh
brew tap gregoryyy/ush
brew trust gregoryyy/ush      # Homebrew loads third-party taps only once trusted
brew install ush
```

Then add the line Homebrew prints to `~/.zshrc`, open a new terminal, and run `ush ai configure`.

**Release archive:** pick the one for your platform (macOS or Linux, arm64 or amd64), check it, and
run its installer:

```sh
curl -fLO https://github.com/gregoryyy/ushell/releases/download/v0.2.0/ush-0.2.0-darwin-arm64.tar.gz
curl -fLO https://github.com/gregoryyy/ushell/releases/download/v0.2.0/SHA256SUMS
shasum -a 256 -c SHA256SUMS --ignore-missing
tar -xzf ush-0.2.0-darwin-arm64.tar.gz && ush-0.2.0-darwin-arm64/install.sh
```

The installer offers to add the zsh plugin to `~/.zshrc`; open a new terminal afterwards. Then run
`ush ai configure`.

- **From source:** `cd ushgo && go build -o ush ./cmd/ush` in the tagged source. With Go 1.27 the
  release build is reproducible: `just ushgo-release 0.2.0` gives the published checksums.
- **macOS:** the binary is not signed. Download with `curl` as above; a browser download is
  quarantined (`xattr -d com.apple.quarantine ush` after checking the checksum).

## Security

- **Seven findings fixed** from adversarial tests (SECTEST), among them three High:
  - terminal escape sequences could change what the approval prompt showed;
  - `""~` could read your home directory, `~/.ssh` included, without approval;
  - under `sudo`, the settings file could be hard-linked to a root-owned file.
- **What ush sends to the provider:** your requests, the OS, user name and working directory, and
  the output of the commands that run (in propose mode, of the proposals you run), up to 32 KB
  each, with known secret formats redacted. Redaction is pattern-based: on sensitive machines, read
  each command before you run it, or use a local model.
- **Checks on this release:** the test suites on macOS arm64 and Linux arm64, the smoke test on
  the built archives, prompt injection evals with a local model, `govulncheck` (no
  vulnerabilities; ush uses the Go standard library only) and a secret scan of the history.

## Known limitations

- **Agent mode and injected text:** with `--run`, text in command output can steer the model to a
  command ush verifies as read-only, which then runs without asking (SECTEST F8). Changes, secret
  files and network lookups still need approval. On untrusted content, use propose mode (the
  default) or a checker (`-k`).
- **Platforms:** checked on macOS (arm64) and on Linux arm64 (Debian, in a container); Linux amd64
  and Intel Macs are built but not tested.
- **Shells:** zsh only; bash and sh can use the `ush` session.
- **Homoglyphs** in proposed commands are not flagged.
- **The Python implementation** in the tagged source still reports `0.2.0-rc1`; the release is
  the Go binary.
