# ush 0.2.1

`ush`, the `//` shell for zsh: ask in plain language, and ush proposes the shell command that
answers it, on your command line. 0.2.1 adds notes on output and files, keeps explanations, and has
a manual page.

## New since 0.2.0

- **Notes on output and files: Ctrl-X n** (or `ush notes`). On an empty line, notes on the last
  output ush recorded; on a command line, it runs the command and gets notes on its output; on a
  line naming files, notes on those files. A `# comment` is your question. ush says what it sends
  and where, sends at most 200 KB with secrets redacted, and refuses secret files, directories and
  binary files. `ush notes [QUESTION] FILE…` and `… | ush notes QUESTION` work without the plugin.
- **Explanations are kept:** Down on a proposal, or `ush explain`, asks the model once per command
  line; the same command later, in any shell, shows the kept explanation
  (`~/.local/state/ush/explanations.json`, the newest 500).
- **A manual page:** `man ush`, installed by both installers and by Homebrew.
- **The source** moved to `ush/go`, `ush/py`, `ush/shell`, `ush/man` and `ush/docs`; the installed
  files are where they were, so the plugin line in `~/.zshrc` stays valid.

## Install

**Homebrew** (macOS and Linux; builds from the tagged source with Go):

```sh
brew install gregoryyy/ush/ush
```

Then add the line Homebrew prints to `~/.zshrc`, open a new terminal, and run `ush ai configure`.

**Release archive:** pick the one for your platform (macOS or Linux, arm64 or amd64), check it, and
run its installer:

```sh
curl -fLO https://github.com/gregoryyy/ushell/releases/download/v0.2.1/ush-0.2.1-darwin-arm64.tar.gz
curl -fLO https://github.com/gregoryyy/ushell/releases/download/v0.2.1/SHA256SUMS
shasum -a 256 -c SHA256SUMS --ignore-missing
tar -xzf ush-0.2.1-darwin-arm64.tar.gz && ush-0.2.1-darwin-arm64/install.sh
```

The installer offers to add the zsh plugin to `~/.zshrc`; open a new terminal afterwards. Then run
`ush ai configure`.

- **From source:** `cd ush/go && go build -o ush ./cmd/ush` in the tagged source. With Go 1.27 the
  release build is reproducible: `just ushgo-release 0.2.1` gives the published checksums.
- **macOS:** the binary is not signed. Download with `curl` as above; a browser download is
  quarantined (`xattr -d com.apple.quarantine ush` after checking the checksum).

## Security

- **Notes** send the files, piped input or recorded output they name to the provider (or to the
  local model), at most 200 KB, after redaction; secret locations are refused also through links,
  and notes never run as root. The plugin now keeps the last recorded output until the next run
  or the shell's exit, in its private 0700 directory, so Ctrl-X n can use it.
- **Explanations** are stored keyed by a hash of the command line, not the command line, mode 0600.

## Known limitations

- **Agent mode and injected text:** with `--run`, text in command output can steer the model to a
  command ush verifies as read-only, which then runs without asking (SECTEST F8). Changes, secret
  files and network lookups still need approval. On untrusted content, use propose mode (the
  default) or a checker (`-k`).
- **Platforms:** checked on macOS (arm64) and on Linux arm64 (Debian, in a container); Linux amd64
  and Intel Macs are built but not tested.
- **Shells:** zsh only; bash and sh can use the `ush` session.
- **Homoglyphs** in proposed commands are not flagged.
