# ush 0.2.2

`ush`, the `//` shell for zsh: ask in plain language, and ush proposes the shell command that
answers it, on your command line. 0.2.2 fixes small local models.

## Fixed since 0.2.1

- **Tool calls written as text:** with llama3.2:3b, `// list the current directory` printed
  `{"name":"ls","parameters":{…}}` instead of a proposal. The model writes its tool call as text,
  with the command as the name, and Ollama passes that on as text. ush now reads such a call as
  meant and proposes `ls`; the JSON is no longer shown.
- **No endless retries:** when a model keeps making tool calls ush refuses (a tool that doesn't
  exist, or the wrong input), the request stops after three tries with a message, and the
  refusal names the tools the model can use.

## Install

**Homebrew** (macOS and Linux; builds from the tagged source with Go):

```sh
brew tap gregoryyy/ush
brew trust gregoryyy/ush      # Homebrew loads third-party taps only once trusted
brew install ush
```

Then add the line Homebrew prints to `~/.zshrc`, open a new terminal, and run `ush ai configure`.

**Release archive:** pick the one for your platform (macOS or Linux, arm64 or amd64), check it, and
run its installer:

```sh
curl -fLO https://github.com/gregoryyy/ushell/releases/download/v0.2.2/ush-0.2.2-darwin-arm64.tar.gz
curl -fLO https://github.com/gregoryyy/ushell/releases/download/v0.2.2/SHA256SUMS
shasum -a 256 -c SHA256SUMS --ignore-missing
tar -xzf ush-0.2.2-darwin-arm64.tar.gz && ush-0.2.2-darwin-arm64/install.sh
```

The installer offers to add the zsh plugin to `~/.zshrc`; open a new terminal afterwards. Then run
`ush ai configure`.

- **From source:** `cd ush/go && go build -o ush ./cmd/ush` in the tagged source. With Go 1.27 the
  release build is reproducible: `just ushgo-release 0.2.2` gives the published checksums.
- **macOS:** the binary is not signed. Download with `curl` as above; a browser download is
  quarantined (`xattr -d com.apple.quarantine ush` after checking the checksum).

## Security

- A tool call read from text is checked like any other: the schema, ush's policy, and your
  approval. ush adds to it at most the program name the model wrote, and only if that is a
  program on your `PATH`.

## Known limitations

- **Agent mode and injected text:** with `--run`, text in command output can steer the model to a
  command ush verifies as read-only, which then runs without asking (SECTEST F8). Changes, secret
  files and network lookups still need approval. On untrusted content, use propose mode (the
  default) or a checker (`-k`). In 0.2.1's checks, with a 3B local model, it happened in 2 of 36
  runs of the injection eval (a poisoned HTML page).
- **Platforms:** checked on macOS (arm64) and on Linux arm64 (Debian, in a container); Linux amd64
  and Intel Macs are built but not tested.
- **Shells:** zsh only; bash and sh can use the `ush` session.
- **Small local models** (llama3.2:3b) often answer agent-mode questions without running anything,
  with made-up numbers; use a model of 8B or more.
- **Homoglyphs** in proposed commands are not flagged.
