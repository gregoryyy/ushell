# ush 0.2.4

`ush`, the `//` shell for zsh: ask in plain language, and ush proposes the shell command that
answers it, on your command line. 0.2.4 lets the model ask back, propose whole scripts and offer
next steps, adds a research mode that runs and proposes nothing, lets you hide the model's
thinking, and fixes Delete, Home and End in the editor.

## Changed since 0.2.3

- **The model asks back:** when a request is unclear, the model asks instead of guessing. The
  question is shown as `// question`, and with the plugin `// ` is put on your command line for
  the answer:

  ```text
  $ // clean up
  // What should I clean up: stray files here, failed builds, or a tool's caches?
  $ // the .log files, but first just list them
  ```

  On a proposal, `// TEXT` answers it as not run, as before; the hint under the proposal now
  says so.
- **Scripts in propose mode:** for a task that needs more than one line, ush proposes a whole
  script (`sh`, `zsh` or `python3`) as one entry on your command line, its source unexpanded
  between `LANGUAGE -c "$(cat <<'USH_EOF'` and the end marker. Read and edit it there; Enter runs
  all of it as edited, Esc removes it, and `//` continues with what ran.
- **Next steps:** with an answer, the model may offer up to three next steps, listed as `//1`,
  `//2`, `//3`. `//N` picks one; `//` alone goes on with the next step. A step that wasn't
  offered is an error and sends nothing.
- **Research only:** `//? TEXT` or `ush research TEXT` compares the options and answers; ush
  proposes and runs nothing for it, and a tool call the model makes anyway is refused. With the
  plugin, the text needs no quotes.
- **Hide the thinking:** the setting `thinking` (`show`, the default, or `hide`, in
  `ush ai configure`), `USH_THINKING`, and `--no-thinking` / `--thinking` for one run. Only the
  display changes; the request, the conversation and the history are the same.
- **Local models' string booleans:** a local model that sends `"interactive": "true"` as a
  string (llama3.1:8b does) now gets its proposals through; before, ush refused every one of
  them. Only exactly `"true"` and `"false"` are read as booleans, and only for Ollama.

## Fixed since 0.2.3

- **Delete, Home and End** (on a Mac: Fn-Backspace, Fn-Left, Fn-Right) edit the line in the
  `ush>` session, and on a proposal where zsh leaves them unbound, instead of typing `[3~` or
  similar. Page Up and Page Down do nothing there.

## Inside

- **Proposals run only on Enter:** an audit of every propose-mode path found none that starts a
  process before you press Enter on the line; tests in the plugin and the session now check it
  for every key that can act on a proposal (TODO 2.39).
- **Comparing local models:** `tests/models/compare.py` runs ten graded requests against local
  Ollama models and prints a table ([SMOKE](../SMOKE.md#3-comparing-local-models-comparepy)).
  It is not installed.
- **Tests and tools** for both implementations moved out of `src/` (`tests/`, `tools/`).
  Installed paths are unchanged.

## Install

**Homebrew** (macOS and Linux; builds from the tagged source with Go):

```sh
brew tap gregoryyy/ush
brew trust gregoryyy/ush      # Homebrew loads third-party taps only once trusted
brew install ush              # or, from 0.2.x: brew upgrade ush
```

Then add the line Homebrew prints to `~/.zshrc`, open a new terminal, and run `ush ai configure`.
After an upgrade, open a new terminal so that the new plugin is loaded.

**Release archive:** pick the one for your platform (macOS or Linux, arm64 or amd64), check it, and
run its installer:

```sh
curl -fLO https://github.com/gregoryyy/ushell/releases/download/v0.2.4/ush-0.2.4-darwin-arm64.tar.gz
curl -fLO https://github.com/gregoryyy/ushell/releases/download/v0.2.4/SHA256SUMS
shasum -a 256 -c SHA256SUMS --ignore-missing
tar -xzf ush-0.2.4-darwin-arm64.tar.gz && ush-0.2.4-darwin-arm64/install.sh
```

The installer offers to add the zsh plugin to `~/.zshrc`; open a new terminal afterwards. Then run
`ush ai configure`.

- **From source:** `cd src/go && go build -o ush ./cmd/ush` in the tagged source. The archives are
  built with Go 1.27.4, and with it the build is reproducible: `just ushgo-release 0.2.4` gives
  the published checksums.
- **macOS:** the binary is not signed. Download with `curl` as above; a browser download is
  quarantined (`xattr -d com.apple.quarantine ush` after checking the checksum).

## Security

- **New tools, no new permissions:** asking back, next steps and research run nothing. A proposed
  script is a proposal like a command: it runs only when you press Enter on it, as you edited
  it. Control characters in a script, a question or a step are refused, so nothing on the
  command line can hide or rewrite what it shows.
- **Research runs nothing:** a research request is sent without tools, and any tool call the
  model makes in it is refused; nothing reaches the command line or the shell.
- **String booleans** can only set `interactive`, which decides whether a proposal's output is
  recorded for `//`; no permission widens. Anthropic's tool calls are checked as strictly as
  before.
- **Built with Go 1.27.4**, which fixes GO-2026-6859 in Go's `net/http`; `govulncheck` finds no
  vulnerabilities in the archives. Homebrew's Go is 1.27.4 too.

## Known limitations

- **Agent mode and injected text:** with `--run`, text in command output can steer the model to a
  command ush verifies as read-only, which then runs without asking (SECTEST F8). Changes, secret
  files and network lookups still need approval. On untrusted content, use propose mode (the
  default) or a checker (`-k`).
- **Local models and the new tools:** in a comparison of seven local models (Ollama, 3B to 36B),
  only qwen3.8 (27B) asked back, wrote scripts and offered next steps every time. Smaller models,
  and some larger ones, propose a one-line command instead; the core flow (propose, continue,
  agent mode) works from mimo-v2.6:9b up. llama3.2:3b often answers agent-mode questions without
  running anything.
- **Platforms:** checked on macOS (arm64), with the release archive; on Linux, both test suites
  and the conformance tests pass in GitHub Actions (Ubuntu), but the Linux archives are built
  and not run. Intel Macs are built but not tested.
- **Shells:** zsh only; bash and sh can use the `ush` session. bash, fish and sh come in 0.3.0.
- **Homoglyphs** in proposed commands are not flagged.
